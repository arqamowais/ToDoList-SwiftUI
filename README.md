# 📝 ToDoList-SwiftUI
A simple and clean To-Do List application built with **SwiftUI** following **MVVM (Model-View-ViewModel)** architecture. This app helps you manage daily tasks with an intuitive interface, persistent storage, and dark mode suppor

# ✨ Features
➕ Add new tasks\
🗑️ Delete existing tasks\
✅ Mark tasks as completed or pending\
💾 Persistent storage using UserDefaults\
🌙 Full support for Dark Mode\
⚡ Built with modern SwiftUI framework

#  🛠️ Tech Stack
+ **Swift**
+ **SwiftUI**
+ **MVVM Architecture**
+ **UserDefaults** (for local data persistence)

# 🚀 Getting Started

**Prerequisites**
+ macOS with latest Xcode installed
+ Basic knowledge of Swift and SwiftUI

**Installation**

1. Clone the repository:
  > git clone https://github.com/arqamowais/ToDoList-SwiftUI.git

2. Open the project in Xcode:
  > open ToDoList-SwiftUI.xcodeproj

3. Run the app on the simulator or a physical device.

# 📂 Project Structure
```
├── Models          # Task data model
├── Views           # SwiftUI UI components
└── ViewModels      # App logic & state management
```

# 💡 How It Works
+ Tasks are stored locally using UserDefaults
+ Each task has:
  - A title
  - A completion status
+ Changes (add/delete/update) are instantly saved and reflected in the UI
